# 🧠 Body Language Recognition System using MediaPipe & Machine Learning

A real-time human body language classification system using MediaPipe's holistic model, OpenCV for video capture and visualization, and scikit-learn for model training and prediction.

![mediapipe-preview](https://user-images.githubusercontent.com/your-image.png)

---

## 🚀 Features

- 📷 Real-time landmark detection (Face, Pose, Hands)
- 🧾 Landmark data export to CSV
- 🤖 Machine learning classification with scikit-learn
- 🔁 Live video prediction using trained models
- 💬 Emotion recognition support: `Happy`, `Sad`, `Good`, `Bad`

---

## 🧩 Tech Stack

- [MediaPipe](https://google.github.io/mediapipe/)
- [OpenCV](https://opencv.org/)
- [pandas](https://pandas.pydata.org/)
- [scikit-learn](https://scikit-learn.org/)
- Python 3.10+
